Hari ke-1: Dari Nol jadi Bisa HTML

Diposting: Hari ini | Oleh: Andriyano

Awal Cerita

Halo! Nama gue Andriyano. Sebelum hari ini, gue gak tau apa-apa soal web development. Gue cuma tau website itu sesuatu yang lo buka di browser, tapi gimana cara bikinnya? Gue gapapa sama sekali.

Gue punya waktu luang dan kepikiran, "Kenapa gak coba belajar bikin website?" Jadi gue mulai dari nol.

Langkah Pertama

Pertama, gue belajar install VS Code — software buat nulis kode. Awalnya bingung sih, tapi lama-lama biasa aja.

Terus gue belajar HTML. Ternyata HTML itu cuma bahasa markup simpel. Gue bikin halaman pertama gue dengan judul dan paragraf. Sesimple itu.

Lanjut ke CSS

Setelah HTML, gue lanjut ke CSS. CSS ini yang bikin website jadi cakep. Gue kasih warna background, ubah warna tulisan, dan rapiin layout.

Hasilnya? Website gue yang tadinya polos sekarang udah berwarna!

Tombol Pertama

Yang paling seru itu pas gue belajar JavaScript. Gue bikin tombol yang kalau diklik muncul pop-up. Greeeet! Ternyata gue bisa bikin sesuatu yang interaktif!

Yang Gue Pelajari Hari Ini

  • Apa itu HTML dan cara pakainya
  • Cara kasih warna dengan CSS
  • Bikin tombol dengan JavaScript
  • Cara hubungkan 3 file jadi satu website
  • Bikin form input sederhana

Kesimpulan

Ternyata belajar web development itu gak seseram yang gue bayangin. Awalnya gue pikir ini susah banget, tapi kalau lo mulai dari yang simpel dan praktek langsung, lama-lama ngerti.

Ini baru hari pertama. Masih banyak yang harus dipelajari, tapi gue excited buat lanjut besok!
