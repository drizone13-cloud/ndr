Materi: CSS

Level: Pemula

Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang dipakai buat mendesain tampilan website. Kalau HTML itu struktur, CSS adalah makeup-nya!

Cara Pakai CSS

Ada 3 cara pakai CSS:

  • Inline - Langsung di tag HTML: style="color: red;"
  • Internal - Di dalam tag <style> di HTML
  • External - File terpisah dengan ekstensi .css (RECOMMENDED!)

Contoh CSS

/* Bikin background gelap */
body {
    background-color: #1a1a2e;
    color: white;
}

/* Bikin judul merah */
h1 {
    color: #e94560;
}

/* Tombol dengan hover */
button {
    background-color: #e94560;
    color: white;
    padding: 10px 20px;
    border-radius: 8px;
}

button:hover {
    background-color: #ff6b6b;
}

Flexbox

Flexbox adalah cara modern buat layout. Sangat powerful!

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 10px;
}

Tips Belajar CSS

  • Uji berbagai warna di ColorHunt
  • Pahami box model (margin, padding, border)
  • Kuasai Flexbox sebelum Grid
  • Praktek desain dari website yang lo suka
