Materi: JavaScript

Level: Pemula

Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang bikin website jadi interaktif. Dengan JavaScript, lo bisa:

  • Bikin tombol yang bisa diklik
  • Validasi form
  • Manipulasi elemen HTML
  • Simpan data di browser

Cara Pakai JavaScript

Ada 2 cara pakai JavaScript:

// Inline - Langsung di HTML
<button onclick="alert('Halo!')">Klik</button>

// External - File terpisah .js (RECOMMENDED!)
<script src="script.js"></script>

Contoh JavaScript

// Ambil elemen
var tombol = document.getElementById("tombolSaya");

// Tambah event
tombol.addEventListener("click", function() {
    alert("Tombol diklik!");
});

// Manipulasi elemen
var judul = document.getElementById("judul");
judul.innerText = "Judul Baru";
judul.style.color = "red";

Local Storage

Simpan data di browser yang tetap ada walau browser ditutup:

// Simpan data
localStorage.setItem("nama", "Andriyano");

// Ambil data
var nama = localStorage.getItem("nama");

// Hapus data
localStorage.removeItem("nama");

Tips Belajar JavaScript

  • Pahami variabel, function, dan event dulu
  • Praktek bikin fitur kecil
  • Gunakan console.log() buat debug
  • Jangan takut error — itu bagian dari belajar!
