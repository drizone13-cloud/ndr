Hari ke-3: Deploy dan JavaScript Lebih Dalam

Diposting: Hari ini | Oleh: Andriyano

Website Gue Online!

Hari ini special banget. Gue berhasil deploy website ke GitHub Pages! Sekarang siapa aja bisa liat website gue dengan link: https://drizone13-cloud.github.io/ndr/

Rasa bangga banget pas pertama kali buka link itu dan website gue muncul. Bukan cuma di komputer gue, tapi bisa diakses dari mana aja!

Validasi Form

Setelah deploy, gue belajar validasi form. Ternyata website harus ngecek input user sebelum diolah. Kalau nama kosong, email gak valid, atau pesan kosong — harus kasih tau user!

Gue bikin form Contact yang bisa:

  • Cek nama kosong
  • Cek email valid (harus ada @)
  • Cek pesan kosong
  • Alert kalau berhasil

Animasi CSS

Gue juga belajar bikin website makin hidup pakai animasi CSS:

  • Transisi smooth pas hover
  • Fade-in pas buka halaman
  • Card naik dan bersinar pas di-hover
  • Tombol pulse (kedip-kedip)

Website gue sekarang terasa lebih profesional!

Manipulasi Elemen JavaScript

Hal seru lainnya: gue belajar hapus dan reset elemen pakai JavaScript. Di halaman Learn, setiap card punya tombol "Hapus" — dan kalau diklik, card hilang dengan animasi smooth!

Ada juga tombol "Reset Kartu" buat balikin semua card yang udah dihapus.

Local Storage

Favorit gue hari ini: Local Storage! Ini cara simpen data di browser. Gue bikin fitur di Home yang bisa:

  • Simpan nama user
  • Nama tetap ada walau browser ditutup
  • Bisa hapus nama

Yang Gue Pelajari Hari Ini

  • Deploy website ke GitHub Pages
  • Validasi form dengan JavaScript
  • Animasi dan transisi CSS
  • Manipulasi elemen (hapus/reset)
  • Local Storage buat simpan data

Kesimpulan

Hari ke-3 ini melelahkan tapi sangat menyenangkan. Gue ngerasa website gue sekarang bukan cuma "halaman biasa" tapi sesuatu yang interaktif dan bisa dipakai orang lain!

Next step? Mungkin backend atau project baru. We'll see!
