Materi: HTML

Level: Pemula

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa dasar buat bikin website. HTML bukan bahasa pemrograman, tapi bahasa markup yang dipakai buat menyusun struktur halaman web.

Struktur Dasar HTML

Setiap halaman HTML punya struktur dasar seperti ini:

<!DOCTYPE html>
<html>
<head>
    <title>Judul Halaman</title>
</head>
<body>
    <!-- Isi konten di sini -->
</body>
</html>

Tag-tag Penting

  • <h1> sampai <h6> - Judul
  • <p> - Paragraf
  • <a> - Link
  • <img> - Gambar
  • <div> - Container
  • <span> - Inline container

Contoh Praktis

Bikin halaman sederhana dengan judul, paragraf, dan link:

<h1>Selamat Datang!</h1>
<p>Ini website pertama gue.</p>
<a href="about.html">Tentang Gue</a>

Tips Belajar HTML

  • Mulai dari yang simpel dulu
  • Praktek langsung, jangan cuma baca
  • Pahami struktur sebelum lanjut ke styling
  • Gunakan inspect element buat belajar dari website lain
